# Attribution and Implementation Context

These exercises were typed and adapted by Ivan Garza while following **Terraform: The Complete Guide from Beginner to Expert**, taught by **Lauro Fialho Müller**.

- [Course](https://www.udemy.com/course/mastering-terraform-beginner-to-expert/)
- [Instructor's companion repository](https://github.com/lm-academy/terraform-course)

This repository publishes the learner-supplied exercise files with organization, documentation, and maintenance changes described in the [review notes](docs/review-notes.md). It is not a mirror of the complete course, a redistribution of course videos, or an official HashiCorp or AWS project. Course-based work is identified as such rather than presented as an independently designed production system.

Repository preparation and validation automation were developed with AI assistance. The [source map](docs/source-map.md) identifies the supplied material, and the [verification ledger](docs/verification.md) distinguishes observations, learner reports, and configuration-only checks.
